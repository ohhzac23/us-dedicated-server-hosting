## “托管”和“租用”是两回事：先算清托管的真实账单

真把服务器托管进美国机房，1U 机位一年就要花上万元人民币，这还没算跨国运费和装机人工。以一家西海岸洛杉矶机房的公开托管报价为例：

这只是基础机位费，往下加东西，价格很快上去：

- 100M 端口不限流量：加 300 元/月；升到 G 口（1000M）不限流量：加 2000 元/月
- 每增加 1AMP 电源：加 100 元/月
- 服务器内置 IPMI 的话，开通 KVM 接口：300 元/月
- 装一次系统人工费 300 元/次（Linux 和 Windows 都收），正版 Windows 还要按月另付系统授权费

跨国寄机器的运费和手续也得自己搞定。最要紧的一笔账是硬件风险：托管模式下，硬盘、电源坏了，换件成本和停机损失全自己扛；租机房的服务器，硬件故障由机房免费更换。连做托管业务的商家自己都会劝你：没有特殊要求，直接租更划算。这一点恰恰是多数对比文章不讲清楚的——它们只比租用价格，很少把托管侧的费用摊开给你看。
